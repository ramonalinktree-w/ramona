Pixel de Meta

Con un Pixel ID cargado, la página envía PageView al abrirse y el evento de clic cada vez que alguien toca un botón de PedidosYa (con el nombre del local en content_name). Dejalo vacío para desactivar el Pixel. Sirve cualquier nombre sin espacios (se crea como evento personalizado) o un evento estándar de Meta: Lead, Contact, InitiateCheckout, ViewContent, FindLocation, Schedule. Para comprobar que llega: extensión Meta Pixel Helper o Events Manager → Probar eventos.
